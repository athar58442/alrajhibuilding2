# شركة الراجحي للبناء والتعمير - النسخة الفاخرة ثلاثية الأبعاد
## Al Rajhi Building & Construction - Ultra-Luxury 3D Web Platform
**إعداد وتطوير: وكالة آثر للدعايا والإعلان (Athar Advertising)**

---

### 📋 نظرة عامة
تم بناء هذا المشروع كإعادة تصميم وهندسة شاملة (Redesign 100%) للبوابة الرقمية لـ **شركة الراجحي للبناء والتعمير** مع الحفاظ الحرفي الكامل على كافة بيانات الشركة التاريخية، منتجاتها، مصانعها، فروعها الـ 33، وكلمات مجلس الإدارة.

---

### 🚀 تشغيل ومعاينة الموقع
الموقع مبني بهندسة تفاعلية متطورة تعمل فورياً دون الحاجة لأي مكتبات خارجية غير مدعومة:
1. **الخادم الحي التفاعلي:** يعمل حالياً عبر الرابط المحلي: **`http://localhost:8080/`**
2. **التشغيل المباشر كملف مستقل:** يمكن فتح ملف `index.html` في أي متصفح ويب حديث مباشرة.

---

### 💎 المزايا التقنية والإضافات البصرية المعتمدة
1. **المحاكي ثلاثي الأبعاد الحي (Three.js WebGL Engine):**
   - محاكاة تفاعلية حية لأربعة قطاعات رئيسية: جسور الحديد الثقيلة (I-Beam)، حزمة حديد التسليح (Rebar Bundle)، التيوبات والمواسير المجوفة (Hollow Tube)، ولفائف الاستانلس ستيل المصقولة (Stainless Coil).
   - تحكم كامل بالماوس بزاوية 360 درجة مع انعكاسات إضاءة معدنية واقعية (Metallic Roughness / PBR Materials).

2. **الفيديو الوثائقي الرسمي للشركة (Official Vimeo Embed):**
   - تضمين الفيديو التعريفي الرسمي لمنتجات الراجحي للبناء والتعمير (Vimeo ID: `323323304`) بدقة فائقة وبشاشة عرض سينمائية فاخرة داخل الصفحة الرئيسية.

3. **معرض صور المصانع والساحات الحقيقية (Real Factory Yards Gallery):**
   - أرشفة ودمج 19 صورة أصلية فائقة الدقة من مصانع ومستودعات الشركة:
     * صور ساحات حديد التسليح (`rebar.jpg`).
     * خطوط إنتاج مصنع التيوبات والمواسير المسحوبة والمجلفنة (`pipes.jpg`).
     * مستودعات الجسور والكَمَرات الثقيلة (`beams.jpg`).
     * مستودعات قطاع الاستانلس ستيل (`stainless.jpg`).
     * مصنع تطعيج الشينكو والقرميد المعدني (`shinko.jpg`).
     * الصاج المبزر والأسود والمجلفن، الزوايا، الشبك، والمبسطات.

4. **صور القيادة العليا التاريخية (Executive Leadership):**
   - صورة رئيس مجلس الإدارة **م . خالد صالح الراجحي** (`chairman.jpg`) مع كلمته الرسمية.
   - صورة المدير العام **الأستاذ ناصر بن مهدي آل سلطان** (`gm.jpg`) مع كلمته الرسمية.
   - صور صرح الشركة التاريخي (`about.jpg`) ورؤية الشركة المستقبلية (`vision.png`).

5. **دليل الفروع الـ 33 مع محرك بحث ذكي:**
   - تفريغ كامل لجميع فروع ومستودعات المملكة (23 فرعاً لقطاع الحديد + 10 فروع لقطاع الاستانلس ستيل).
   - زر اتصال هاتفي وزر محادثة واتساب مباشر لكل فرع برقم المسؤول المعتمد.

6. **حاسبة أوزان حديد التسليح الذكية:**
   - أداة متخصصة لمهندسي ومقاولي المشاريع لحساب الأوزان الطولية والإجمالية بالأطنان وفق معادلة كود البناء السعودي ($W = D^2 / 162$).

7. **شعار الراجحي بالذهب الملكي الشفاف (Luxury Metallic Gold Emblem):**
   - شعار عالي الدقة بدون خلفية زرقاء مفرغ بحواف ناعمة ذهبية متناسق تماماً مع الهوية الفاخرة للشركة (`logo.png`).
